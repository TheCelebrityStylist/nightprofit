# Roadmap

Launch contains reconciliation, event contribution, beverage margin control and evidence-backed owner briefings. Add modules only after the core has reliable source coverage:

- Group Booking Revenue Agent: after booking-source ingestion, permission model and attribution tests exist.
- Supplier and Contract Guard: after contract document review and renewal-date evidence are supported.
- Event Yield Planner: after at least twelve comparable events and forecast back-testing.
- Staff Compliance & Onboarding OS: after jurisdictional requirements, document retention and restricted HR permissions are designed.

Each module must register entitlements, navigation, permissions, adapter interfaces, event hooks, activity events, documents and notifications. No module appears in production navigation until complete.
